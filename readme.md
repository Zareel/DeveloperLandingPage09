# Developer Landing Page 🚀

A responsive **Developer Landing Page** built using **HTML5** and **CSS3**.
This project is ideal for practicing **layout design, responsiveness, and modern UI structuring** using pure CSS (no frameworks).

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **Google Fonts (Poppins)**
* **Responsive Design (Media Queries)**

---

## ✨ Features

* Fully responsive landing page
* Modern navigation bar
* Hero section with text & image
* API category cards
* Blog section with cards
* FAQ section
* Email download form
* Footer with social icons
* Clean UI with consistent color theme
